# Glossário — Comunidade vs Premium

## Regra mestra
A palavra **"curador"** NUNCA aparece em telas públicas, onboarding, convites, dashboard da comunidade, emails para membros ou copy de marketing da Comunidade.
Ela existe SOMENTE no painel admin/premium (operação interna).

## Vocabulário público (Comunidade — Fase 0)
| Conceito | Termo correto | Exemplos de uso |
|---|---|---|
| Pessoa que entra por convite | **parceiro** ou **membro** | "Você é parceiro NexEngine", "Convide novos membros" |
| Quem cadastra playlist | **criador de playlist** | "Cadastre sua playlist" |
| Coletivo | **comunidade** | "Bem-vindo à comunidade" |
| Ato de divulgar campanha | **apoiar / participar** | "Apoie esta campanha", "Participe de campanhas" |
| Recompensa | **pontos** ou **créditos** | NÃO usar "pagamento", "cachê", "comissão" no público |
| Aprovação de faixa | **aceitar / passar** | "Aceitar campanha" |

## Vocabulário interno (Premium / Admin)
"curador", "deal", "payout", "cachê", "BRL", "fraude", "tier", "score" — só no admin.

## Tom
- Pouco texto. Frases curtas. Verbo no imperativo.
- Zero saudação ("Olá", "Bom dia"), zero emoji, zero linguagem emocional.
- Mobile-first: cada tela cabe em 1 dobra de celular.
- Usuário entende a tela em <10 segundos.

## Posicionamento
Comunidade NÃO é marketplace. É **rede de descoberta** que recompensa quem ajuda música boa circular. Foco: hábito, rede, dataset — não receita.
