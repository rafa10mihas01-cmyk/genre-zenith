---
name: Correções globais de DEL
description: Ajustes em portal/histórico/progresso de DEL devem valer para todos os deals, nunca para um caso isolado
type: feature
---
Quando corrigir comportamento de DEL (portal do curador, histórico de prints, progresso, playlists, baselines ou contagens), implementar na fonte global compartilhada por todos os deals.

Nunca resolver apenas pelo ID, slug, campanha ou música que o usuário mostrou como exemplo. Use o exemplo só para reproduzir e valide com outros DELs antes de concluir.
